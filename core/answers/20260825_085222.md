# Q: 阿司匹林一级预防心血管疾病的获益和出血风险如何权衡？请检索文献回答


**结论 / Bottom line**:  
阿司匹林在心血管疾病一级预防中可降低严重血管事件风险，但增加出血风险，其获益与风险的平衡因人群而异。对于糖尿病患者、慢性肾病患者或特定基因型（如高脂蛋白(a)基因风险）人群，阿司匹林的获益可能超过出血风险；但对一般人群，风险与获益可能相当，需谨慎评估个体化获益。

**证据 / Evidence**:  
- **糖尿病患者**：阿司匹林降低严重血管事件风险8%（HR 0.88），但增加主要出血风险29%（HR 1.29），绝对获益与风险大致相当 [1]。  
- **高脂蛋白(a)基因型人群**：rs3798220-C携带者或高LPA-GRS亚组中，阿司匹林显著降低心血管事件风险（HR 0.54-1.41），且不增加出血风险 [2]。  
- **慢性肾病患者**：Lp(a) ≥50 mg/dL者，阿司匹林降低心肌梗死风险38%（HR 0.62）和终末期肾病风险28%（HR 0.72），无显著出血风险 [9]。  
- **基因风险分层**：高遗传风险组（q5）中，阿司匹林降低CAD事件风险47%（HR 0.53），且无出血风险增加 [3]。  

**局限 / Caveats**:  
- 不同研究人群异质性大，需结合个体风险因素（如基因型、合并症）评估。  
- 长期使用阿司匹林的出血风险累积效应尚不明确。  
- 部分研究样本量较小或随访时间有限，需更多高质量RCT验证。
