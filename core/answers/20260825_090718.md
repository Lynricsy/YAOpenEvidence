# Q: 二甲双胍对非糖尿病人群的心血管保护作用有证据吗？

**结论 / Bottom line**  
目前证据表明，二甲双胍在非糖尿病人群中心血管保护作用的证据有限且不一致。尽管部分研究提示其可能通过改善血管内皮功能或降低心衰标志物（如NT-proBNP）发挥潜在益处，但尚无明确结论性数据支持其在非糖尿病人群中的心血管获益。正在进行的VA-IMPACT试验（NCT02915198）可能进一步澄清这一问题。  

**证据 / Evidence**  
- **系统综述（RCTs）**：在糖尿病和非糖尿病患者中，二甲双胍可降低心衰标志物（如NT-proBNP和LDL），但效果在非糖尿病患者中不一致 [2]。  
- **Meta分析**：糖尿病患者使用二甲双胍的全因死亡率低于非糖尿病人群（HR=0.93, 95%CI 0.88–0.99），但未直接评估非糖尿病人群的心血管结局 [5]。  
- **观察性研究**：在高心血管风险的非糖尿病人群（如糖尿病前期）中，二甲双胍可能延缓糖尿病进展（糖尿病发生率降低约25%），但未显示明确的心血管事件减少 [8]。  

**局限 / Caveats**  
- 非糖尿病人群的证据主要来自亚组分析或使用替代终点的试验，缺乏直接心血管结局的高质量研究 [8]。  
- 现有研究中，非糖尿病患者的样本量较小或统计效力不足，无法明确心血管获益 [8]。  
- 二甲双胍的潜在心血管作用可能部分归因于其改善胰岛素抵抗的机制，而非直接针对非糖尿病人群的病理生理特征 [2]。  
- 早期试验在非糖尿病人群中未显示对颈动脉内膜中层厚度（cIMT）或心血管替代指标的显著影响 [8]。
