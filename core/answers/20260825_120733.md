# Q: 二甲双胍对非糖尿病人群的心血管保护作用有证据吗？

**结论 / Bottom line**  
目前证据表明，二甲双胍在非糖尿病人群中心血管保护作用的证据有限且不一致。尽管部分研究提示其可能通过改善胰岛素抵抗和炎症标志物对心脏功能有益，但缺乏直接针对非糖尿病人群的大规模随机对照试验（RCT）结果。观察性研究和亚组分析的结论尚需进一步验证。

**证据 / Evidence**  
- **系统综述（RCTs）**：在糖尿病和非糖尿病患者中，二甲双胍可降低心衰标志物（如NT-proBNP）和低密度脂蛋白水平，但非糖尿病患者的结果不一致 [2]。  
- **荟萃分析**：糖尿病患者使用二甲双胍的全因死亡率低于非糖尿病人群（HR=0.93, 95%CI 0.88-0.99），但未直接评估非糖尿病人群的心血管结局 [5]。  
- **叙事综述**：在高心血管风险的非糖尿病人群（如糖尿病前期）中，二甲双胍可能延缓糖尿病进展，但心血管事件的减少未在长期随访中明确证实 [8]。  

**局限 / Caveats**  
- 非糖尿病人群的直接证据主要来自亚组分析或替代终点，缺乏大样本RCT支持 [8]。  
- 现有研究可能受混杂因素（如他汀类药物使用）影响，导致结果偏倚 [8]。  
- 二甲双胍的心血管益处可能部分依赖于其降糖作用，而非糖尿病人群的独立效应尚不明确 [1,2]。  
- 部分研究因治疗交叉或随访时间不足，削弱了结论的可靠性 [6]。
