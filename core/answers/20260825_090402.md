# Q: SGLT2抑制剂对射血分数保留型心衰(HFpEF)患者有什么获益？

**结论 / Bottom line**  
SGLT2抑制剂在HFpEF患者中可改善症状（如生活质量、6分钟步行距离）和心脏重构，但对心血管死亡或住院率的获益证据尚不明确。部分研究提示其可能减少心衰住院风险，但需更多长期数据验证。  

**证据 / Evidence**  
- **系统综述和荟萃分析**：Empagliflozin在HFpEF患者中对心脏重构和功能的改善作用优于其他亚组（如HFrEF），但未报告心血管死亡或住院率的显著降低 [1]。  
- **随机对照试验（DECLARE-TIMI）**：Dapagliflozin可降低HFpEF患者心衰住院风险（HR 0.76, 95% CI 0.62–0.94），但未显著降低死亡率 [3]。  
- **短期试验（12周）**：Dapagliflozin显著改善HFpEF患者的生活质量评分（KCCQ-CS提高5.8分）和6分钟步行距离（增加20.1米） [4]。  
- **机制研究**：SGLT2抑制剂通过减少心肌纤维化、改善能量代谢和炎症反应等机制可能对HFpEF有益 [5]。  

**局限 / Caveats**  
- 多数研究随访时间较短（如12周），无法评估长期结局（如死亡率或住院率） [4]。  
- HFpEF患者数据有限，部分试验（如DELIVER）结果尚未公布 [3]。  
- 不同研究对HFpEF的定义和纳入标准存在异质性 [3]。  
- 现有证据主要基于糖尿病患者，非糖尿病HFpEF人群的获益尚需验证 [5]。
