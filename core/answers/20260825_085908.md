# Q: PMC9306514 这篇文章的实验用了什么动物、样本量多少、主要结果是什么？请读全文的 Methods 和 Results 回答


**结论 / Bottom line**  
该研究使用无线植入式传感器测量绵羊的下腔静脉（IVC）横截面积，发现IVC面积变化比右心房压力（RAP）和肺动脉压（PAP）更敏感。实验共纳入9只绵羊，样本量适中。主要结果表明，在容量负荷和血管扩张情况下，IVC面积变化比压力指标更早、更显著。

**证据 / Evidence**  
- **动物与样本量**：实验在9只农场绵羊（均重70 kg）中进行，符合动物福利法规 [1]。  
- **硝酸甘油实验**：IVC面积减少18.3%，而RAP和PAP分别减少8.1%和11.0%（IVC变化更显著，p < 0.001） [1]。  
- **容量负荷实验**：注入500 ml液体后，IVC面积增加60%，而RAP仅增加20%；高容量时IVC变化与压力变化的敏感性差异缩小 [1]。  
- **快速心脏起搏实验**：IVC面积增加19.0%，RAP和PAP分别增加12.9%和5.1%（IVC变化更显著，p ≤ 0.02） [1]。  

**局限 / Caveats**  
- 样本量较小（n=9），可能限制结果的普遍性。  
- 实验仅在绵羊中进行，需进一步验证人类适用性。  
- 容量实验中压力-IVC关系的非线性可能受个体差异影响。
